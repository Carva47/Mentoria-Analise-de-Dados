O que é esta mentoria

Nos próximos meses vamos percorrer, juntos, o ciclo completo do trabalho de um analista de dados — do primeiro clique no Excel a um projeto final que podes mostrar a um empregador ou cliente.
  • Não é um curso de vídeos gravados: é acompanhamento direto, sessão a sessão, com correção do que fizeres
  • Todo o percurso é construído sobre os dados de uma rede de lojas fictícia, mas realista — a mesma base de dados atravessa todos os módulos
  • O objetivo final não é um certificado: é um portefólio de trabalho real, defensável perante qualquer pessoa
Formato

Como vamos trabalhar

  • Sessões ao vivo, online, às segundas e sextas
  • Duração de 60 a 90 minutos por sessão, com a ferramenta sempre aberta e partilhada no ecrã
  • Nos dias entre sessões, exercícios práticos para consolidar o que foi visto — sem eles, o ritmo não se sustenta
  • Um canal aberto para dúvidas fora das sessões, para não ficares bloqueado(a) sozinho(a) vários dias

Regras do jogo

Para o ritmo se sustentar

  • Avisa com antecedência se não puderes comparecer a uma sessão
  • Os exercícios fazem-se nos dias entre sessões, não na véspera da sessão seguinte
  • Se ficares bloqueado(a) mais de 20 minutos num exercício, para e anota a dúvida — não percas a tarde inteira sozinho(a)
  • Guarda tudo o que fizeres, mesmo o que correu mal — vamos precisar disso no projeto final
